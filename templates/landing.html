Quick start

GET 接口，
小白也能用

注册并由管理员开通有效期后，在控制台创建 API Key。推荐使用请求头传递密钥，也兼容直接放入查询参数。

注册账号 进入控制台
GET /api/v1/parse

# 最简单的 URL 调用方式

GET /api/v1/parse?key=mp-xxx&url=分享链接

# 推荐：密钥放在请求头

curl --get 'https://your-domain.com/api/v1/parse' \

--header 'Authorization: Bearer mp-xxx' \

--data-urlencode 'url=https://v.douyin.com/xxx/'

# 返回

{ "succ": true, "data": { "platform": "抖音", "video_url": "https://..." } }
